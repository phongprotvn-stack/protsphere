## 2. RBAC (Role-Based Access Control)

| Vai trò | Xem | Bình luận | Sửa | Thêm/Xoá | Import/Export | AI | Cấu hình |
|---------|-----|-----------|-----|---------|--------------|----|---------|
| **Public (Guest)** | ✅ Trang chủ, thống kê cơ bản, timeline công khai | ❌ | ❌ | ❌ | ❌ | ❌ | ❌ |
| **Viewer** | ✅ Tất cả dữ liệu (read-only) | ✅ Thêm bình luận/emoji | ❌ | ❌ | ❌ | ❌ | ❌ |
| **Contributor** | ✅ Tất cả | ✅ | ✅ Sửa thông tin cá nhân được gán | ❌ | ❌ | ❌ | ❌ |
| **Editor** | ✅ Tất cả | ✅ | ✅ Toàn bộ | ✅ Thêm/Xoá | ✅ | ✅ | ❌ |
| **Admin (Prot)** | ✅ Tất cả | ✅ | ✅ Toàn bộ | ✅ Toàn bộ | ✅ | ✅ | ✅ |

## 3. Firebase Auth + Firestore Security Rules

- Authentication: Google Sign-in via Firebase Auth
- Admin UID duy nhất (Prot)
- Firestore rules:

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // Admin-only collections (users write through API)
    match /users/{userId}/{document=**} {
      allow read: if request.auth != null 
        && (request.auth.uid == userId 
            || request.auth.token.admin == true);
      allow write: if request.auth.uid == 'ADMIN_UID';  // API only
    }
    
    // Public collections (readable by anyone)
    match /public/{document=**} {
      allow read: if true;
      allow write: if request.auth.uid == 'ADMIN_UID';
    }
  }
}
```

## 5. Backend API Endpoints

### Auth
- `POST /api/auth/verify` — Verify Firebase ID token, return roles
- `GET /api/auth/me` — Current user info + permissions

### People CRUD (all through API)
- `GET /api/people` — List people (filtered by RBAC)
- `GET /api/people/:id` — Get person detail
- `POST /api/people` — Create person
- `PUT /api/people/:id` — Update person
- `DELETE /api/people/:id` — Delete person

### Events / Memories / Places (mirror pattern)

### Import / Export
- `POST /api/import/sheets` — Import from Google Sheets
- `POST /api/import/upload` — Upload file (JSON/Excel/PDF)
- `GET /api/export/json` — Export all data as JSON
- `POST /api/export/sheets` — Export to Google Sheets

## 6. Frontend changes
- Remove direct `syncToFirestore` / `loadFromFirestore` / `subscribeToFirestore`
- Add `src/api/client.js` — fetch wrapper with auth token
- Update `AppContext.jsx` — call backend API for all mutations
- Keep localStorage as cache (read-through)
- Firebase Auth stays on client (sign-in), but writes go through API

## 7. Deployment
- Frontend: Vercel (as now)
- Backend: Vercel Serverless Functions (`api/` directory)
- No additional server needed
