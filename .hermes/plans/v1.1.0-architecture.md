# PROT SPHERE v1.1.0 — Kiến trúc dữ liệu

## Luồng dữ liệu

```
Google Sheet (Mối quan hệ)
  ├── Apps Script A (Mối quan hệ)
  │     └── onEdit / timer 5 phút ──→ Firestore (collection "people")
  │
Google Sheet (Sự kiện)
  ├── Apps Script B (Sự kiện)
  │     └── onEdit / timer 5 phút ──→ Firestore (collection "events")
  │
App nhập liệu khác (Airtable / Form / iOS Shortcut...)
  └── Apps Script C / Webhook ──→ Firestore

Web (React)
  └── Firestore onSnapshot ──→ local cache ──→ UI

          ┌────────────────────────────────────┐
          │ Firebase Firestore                 │
          │   collections:                     │
          │     people/{doc}                   │
          │     events/{doc}                   │
          │     memories/{doc}                 │
          │     places/{doc}                   │
          │     tags/{doc}                     │
          └────────────────────────────────────┘
                    ▲
                    │ onSnapshot (real-time)
                    │
          ┌────────────────────────────────────┐
          │ Web App (React + Vite)             │
          │   - Chỉ đọc từ Firestore           │
          │   - Ghi trực tiếp lên Firestore    │
          │     (khi user thêm/sửa/xoá trên UI)│
          │   - localStorage = cache fallback  │
          └────────────────────────────────────┘
```

## Steps thực hiện

1. Xoá code sheet sync cũ (client-side fetch CSV, useSheetSync, useMultiSourceSync, sheetFetch)
2. Đơn giản hoá AppContext — chỉ đọc/ghi Firebase, localStorage cache
3. Viết Apps Script mới:
   - Đọc sheet → build JSON → Firestore REST API (push/tuỳ chỉnh)
   - onEdit trigger + time-based trigger (5 phút)
4. Settings Tab → bỏ "Data Sync" cũ (source URLs), giữ Auth + Language + Export/Import/Clear
5. Deploy
